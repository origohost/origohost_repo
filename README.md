# OrigoHOSTs Community Platform

![OrigoHOSTs Banner](https://via.placeholder.com/1200x400?text=OrigoHOSTs+Community)

The enterprise-grade platform powering the OrigoHOSTs Community — a network of 90,000+ developers, builders, and founders across India. Built for speed, scale, and seamless community operations.

## 🚀 Quick Start

1. **Clone the repository**

   ```bash
   git clone https://github.com/origohosts/community.git
   cd community
   ```

2. **Install Dependencies**

   ```bash
   npm install
   ```

3. **Environment Setup**

   ```bash
   cp .env.example .env
   # Populate .env with your Supabase credentials
   ```

4. **Run Development Server**
   ```bash
   npm run dev
   ```

## 🛠️ Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start) / React 19
- **Routing**: [TanStack Router](https://tanstack.com/router)
- **Data Fetching**: [TanStack Query](https://tanstack.com/query)
- **Styling**: Tailwind CSS v4 & Framer Motion
- **Database / Auth**: [Supabase](https://supabase.com)
- **Email**: [Resend](https://resend.com)
