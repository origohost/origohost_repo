## 5. Writing Guidelines

### Headlines and Headings
- Be direct and specific: avoid vague headlines like "Welcome to the Future."
- Lead with what the user gains: "Build Real Projects with Real Engineers."
- Use sentence case for body headings; title case for hero display text only.
- Avoid exclamation marks in formal headings.

### Body Copy
- Use short paragraphs (2–4 sentences maximum in any single block).
- Prefer active voice.
- Avoid jargon unless writing for a technical audience where precision is valued.
- Define acronyms on first use.

### CTAs (Calls to Action)
- Use action verbs: "Join the Community", "Explore Events", "Apply Now", "Get Involved."
- Be specific: "Register for CyberForge 2026" beats "Learn More."
- Primary CTA must be singular and clear per section.

### Event and Program Descriptions
- Always specify type, format and delivery mode.
- Be accurate about audience and prerequisites.
- Do not describe a webinar as a "workshop" or a training program as a "course" unless correct.

### Statistics and Claims
- Every public statistic must carry a defined metric, time period and source.
- Do not aggregate metrics with different definitions.
- Do not round up or estimate without stating so.
- Avoid: "one of India's leading communities" — unless a verified source confirms this.

### Partnership and Relationship Descriptions
- Only use the word "partner" for confirmed partnerships.
- Specify the nature: "Technology Partner", "Knowledge Partner", "Institutional Collaborator."
- Do not list organizations as sponsors without confirmed sponsorship.

## 6. Language to Use vs Avoid

### Use
| Use | Rationale |
|-----|-----------|
| "builders" | Core brand audience descriptor |
| "innovators" | Core brand transformation |
| "ecosystem" | Accurately describes OrigoHOST's model |
| "community" | Core operational identity |
| "practical experience" | Core brand differentiator |
| "collaborate" | Core community value |
| "India-origin" / "India-based" | Accurate geographic identity |
| "workshops", "hackathons", "meetups" | Specific verified activity types |

### Avoid
| Avoid | Reason |
|-------|--------|
| "World-class" | Unverifiable superlative |
| "Largest" / "Biggest" | Unverifiable unless sourced |
| "Premier" | Unverifiable without evidence |
| "Revolutionary" | Marketing hype |
| "Disruptive" | Overused, imprecise |
| "Empowering India's youth" | Generic, clichéd |
| "Join our family" | Inconsistent with technical brand voice |
| "Game-changing" | Marketing hyperbole |
| "We are the future" | Unsupported claim |
