# DESIGN EXECUTION GUIDELINES (ANTI-AI STYLE)
- Do NOT use generic SaaS landing page structures (Hero -> 3 Feature Cards -> Testimonials -> Pricing).
- Create a distinct, editorial aesthetic using creative layouts, asymmetric spacing, and unexpected grid structures.
- Avoid default AI visual tropes: No neon purple/blue futuristic gradients, and no glowing borders around cards unless specified.
- Prioritize high-end typography: Use a bold, expressive header font paired with an ultra-clean, highly readable body font.
- Implement organic micro-interactions: Every button, link, and card must feature smooth spring animations using Framer Motion on hover and active states.
- Ensure strict visual consistency: Standardize corner rounding (e.g., `rounded-xl` maximum), border weights, and spacing tokens.
